### D-02: Support bundle live-smoke summary is shallow for schema v2 — closed by Phase 52

**Affected requirement:** OBS-03

The Phase 50 support evidence recorded the selected live-smoke report path, but
the allowlisted summary field reported `summary_fields_unavailable`. Phase 52
closes this deterministic debt for future support bundles: support ingestion now
prefers schema v2 nested `result` fields for status, progress detection, typed
cause, next action, header delta, and block delta, while preserving the
top-level compatibility fallback and keeping raw logs, raw report inputs,
options, snapshots, and endpoint tables out of support JSON and Markdown.

**Affected requirements:** PROOF-03, PROOF-04, PROOF-05, OBS-02, SEC-03

The committed Phase 50 UAT intentionally preserves the selected generated report
as historical evidence. That report used `getblockchaininfo` snapshots and shows
the stale `rpc_getblockchaininfo` phase. Phase 53 appends a fresh evidence
supersession to Phase 50 UAT and selects a new manual-peer report whose
snapshots come from `openbitcoinsyncstatus`. The selected Phase 53 report closes
the stale-artifact caveat through fresh diagnosed-blocker evidence, not by
rewriting the historical Phase 50 artifact.

### D-04: `open-bitcoind` preflight message is stale — closed by Phase 52

**Affected requirement:** OBS-02

`open-bitcoind` starts the current opt-in daemon sync worker, and Phase 52
refreshes its preflight stderr to say the durable store opened and enabled
startup will run the explicit opt-in bounded mainnet sync worker. The refreshed
message preserves the non-claims that this is not unattended production-node
operation and is not a packaged-service guarantee.
