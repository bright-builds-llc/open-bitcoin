## Passed Cross-Phase Flows

- Config -> admission -> status/support/RPC is wired. Config and CLI resolve into `InboundListenerConfig`, daemon activation records listener evidence, accept-loop admission records are collected, and `current_inbound_status()` feeds RPC, status, and support surfaces.
- Permission -> admission/address/eviction evidence is wired. Permission classes resolve by remote IP, admission records preserve permission decisions, bounded `getaddr` eligibility consumes active permission effects, and protected peers feed eviction and misbehavior evidence.
- Address -> bounded `getaddr`/learned status is wired. `getaddr` and `addr` handling update bounded address evidence, and managed status projects that evidence.
- Resource governance -> status/log/support is wired apart from retained metric history. Runtime resource events call `record_inbound_resource_event`, append JSONL when configured, and render through status and support.
- Peer-policy runtime -> reconnect suppression/status/RPC/CLI/support is wired after Phase 96. Automatic structured-log emission remains the INT-04 edge.
