## Assets

- Canonical txid/wtxid identity pairs, request order, shape bounds, and package fingerprint integrity.
- CPU/memory budget before contextual validation or scripts.
- Truthful report states that cannot counterfeit committed lifecycle membership.

## Trust Boundaries

| Boundary | Untrusted input crossing it |
| --- | --- |
| Caller transaction vector → `WellFormedPackage` | Arbitrary count, weight, ordering, identities, and outpoints |
| Well-formed package → submission refinement | Claimed child/parent relationship against immutable chainstate |
| Ordered members → report/group constructors | Result identities, group ids, fee totals, and alias claims |

## Threats and Mitigations

| Threat ID | STRIDE | Threat | Disposition | Concrete mitigation |
| --- | --- | --- | --- | --- |
| T-132-01 | Denial of Service | Malformed/oversized package triggers hashing, chainstate, or script work | mitigate | Task 1 enforces empty/25/404000/identity/topology/conflict bounds in the opaque constructor before admission |
| T-132-02 | Spoofing/Tampering | Same txid/different witness is treated as the requested witness being admitted | mitigate | Task 2 requires `SameTxidDifferentWitness { requested, existing_wtxid }` and forbids a fee-group id |
| T-132-03 | Tampering | Fingerprint sorting silently changes response order | mitigate | Task 1 hashes a temporary sorted wtxid copy while private member storage remains request ordered |
| T-132-04 | Tampering/Repudiation | A caller forges or mutates a report/group whose fields misalign member order, cardinality, status, or fee membership | mitigate | Task 2 keeps every invariant-bearing field private, requires checked `try_new`, exposes read-only accessors, and runs E0451/E0616 compile-fail API tests |
| T-132-05 | Denial of Service | Weight/fee aggregation wraps or saturates into a passing bound | mitigate | Tasks 1–2 use checked addition and typed constructor errors; boundary tests exercise limit+1 |
| T-132-06 | Elevation of Privilege | A caller directly constructs the submission-only child-with-unconfirmed-parents capability from a raw well-formed package | mitigate | Task 1 uses a private-field refinement, makes `try_from_package` the only public constructor, and runs an E0451 direct-construction compile-fail doctest |
