Required rule order:
```text
exactly two new residual members
new parent is direct parent of new child
neither new member has an in-mempool ancestor
checked running sum of each direct conflict's descendant count <= 100, counting overlap
only then allocate deterministic union of direct conflicts + descendants
new modified fee >= originals + incremental fee(package vsize)
new package feerate > new parent feerate
new feerate diagram strictly dominates old diagram
stage all removals before package topology/limit revalidation
```
