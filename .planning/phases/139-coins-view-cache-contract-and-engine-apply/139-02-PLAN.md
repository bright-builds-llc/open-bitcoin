Knots AddCoin FRESH rule (`coins.cpp` 72-103): when overwriting a spent occupancy, `fresh = !existing.IsDirty()`. When `possible_overwrite` is false and HaveCoin (unspent) is true, return `ChainstateError::OutputOverwrite` — do not port coinbase-always-overwrite.

Knots SpendCoin (`coins.cpp` 130-149): FRESH → erase occupancy; else SetDirty and clear coin (`maybe_coin = None`). Missing unspent → `MissingCoin` (not Knots silent false). Return the live Coin for undo (`moveout`).

Knots BatchWrite (`coins.cpp` 183-247): skip non-dirty; parent miss + FRESH+spent → ignore; parent miss + otherwise → insert DIRTY and copy FRESH; parent hit + child FRESH + parent unspent → `FreshFlagMisapplied`; parent FRESH + child spent → erase parent; else overwrite coin, SetDirty, do not mark parent FRESH.
