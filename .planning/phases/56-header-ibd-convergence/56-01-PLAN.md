<objective>
Prove daemon-integrated header sync can advance through validated multi-batch
header progress, stop with an explicit convergence diagnosis, persist header
height durably, and emit first-header-progress evidence from opt-in live smoke.
</objective>

<threat_model>

## Threat Model

- **False progress:** Only accepted headers may advance header height or
  contribution counters.
- **Unbounded sync loop:** Header sync must stop at configured target,
  no-progress diagnosis, or max rounds.
- **Lost durability:** Header progress must remain visible after runtime reopen
  and through status projection.
- **Public-network nondeterminism:** Default verification must not require
  reachable public peers.
- **Scope creep:** Do not claim block download/connect success in this phase.

</threat_model>
