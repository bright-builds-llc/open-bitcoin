Knots `GetMinFee` control flow (RESEARCH Pattern 2):
1. If `!block_since_last_rolling_fee_bump || rolling == 0` → return llround(rolling) without decaying
2. Else if `now > last_update + 10`:
   - `rolling /= pow(2.0, dt / halflife)` with occupancy-adjusted halflife
   - `last_update = now`
   - if `rolling < incremental/2` → rolling = 0
3. Return llround(rolling)

Open Bitcoin intentional difference (D-06 / Phase 130):
- Do NOT return `max(llround(rolling), incremental)` as effective admission
- Expose raw rolling via `RollingMempoolFeeRate`; derive effective as `max(static, rolling)` only

`removeForBlock` gate open (mirror in `remove_for_connected_block_transition`):
- After connect removals: `block_since_last_rolling_fee_bump = true`
- `last_rolling_fee_update = context.connected_at`
