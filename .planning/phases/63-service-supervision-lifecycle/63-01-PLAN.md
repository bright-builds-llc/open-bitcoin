<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI -> service manager preview | Untrusted CLI flags and paths are converted into generated service definitions and preview text. |
| operator binary path -> daemon binary resolver | The running operator executable path is inspected to choose the daemon executable used by service files. |
| selected datadir/config/log paths -> generated launchd/systemd content | Operator-controlled paths are embedded into plist/unit content without executing shell strings. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-63-01-01 | Tampering | `resolve_service_daemon_binary` | mitigate | Prefer only a concrete sibling file named `open-bitcoind`; otherwise use literal command `open-bitcoind`. Test both branches and do not accept arbitrary service binary flags in this phase. |
| T-63-01-02 | Elevation of Privilege | generated service definitions | mitigate | Preserve user-level launchd/systemd paths and output `Scope: user-level`; do not add sudo, `/Library/LaunchDaemons`, `/etc/systemd/system`, or machine-wide install paths. |
| T-63-01-03 | Tampering | install/preview dispatch | mitigate | Keep `install` dry-run unless `--apply`; make `preview` reject `--apply` and call no manager method when rejected. |
| T-63-01-04 | Information Disclosure | preview output | accept | Preview intentionally displays generated content and configured paths for operator review; do not include credential contents, cookie values, or source datadir mutation instructions. |
| T-63-01-05 | Tampering | Bitcoin Core/Knots source services/datadirs | mitigate | Generated file paths remain Open Bitcoin user service paths and selected Open Bitcoin datadir/config/log paths only; tasks explicitly prohibit source service or source datadir mutation. |
</threat_model>
