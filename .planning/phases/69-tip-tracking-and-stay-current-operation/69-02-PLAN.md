<threat_model>
## Security And Correctness Notes

- This plan does not add a public tip API, oracle, checkpoint, assumevalid,
  assumeutxo, inbound serving, relay, or public-network default verification.
- Malicious peers can advertise false, stale, or lagging tip evidence; the
  mitigation is to base best-known status on validated headers and separately
  classify bounded peer agreement evidence.
- Stale/no-progress classification can mislead operators if it depends on real
  wall-clock sleeps; deterministic tests must use fixed timestamps.
- New `sync/tip.rs` must receive parity breadcrumbs because it is first-party
  Rust source under `packages/open-bitcoin-*/src`.
</threat_model>
