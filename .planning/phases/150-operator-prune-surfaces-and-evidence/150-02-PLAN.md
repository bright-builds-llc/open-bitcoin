# Phase 150 Plan 02: JSONC Prune Mode Reaches the Node

<objective>
Wire the existing `parse_prune_arg` integer into top-level `open-bitcoin.jsonc` field `prune` and apply that `PruneMode` when the RPC context builds the network handle (OPER-01; D-06, D-07, D-08, D-20).

Purpose: Production startup currently constructs `PruneMode::Disabled` and never calls `set_prune_mode`, so later reads would stay false. This plan does not add a second parser or a parallel byte field.
Output: JSONC field, loader mapping, startup `set_prune_mode`, and config tests.
</objective>
