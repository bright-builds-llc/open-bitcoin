## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Peer wire message -> peer negotiation state | Remote peers can send valid, repeated, contradictory, or unsupported `sendcmpct` messages that become local per-peer state. |
| Peer negotiation state -> future announcement policy | Stored compact capability will later influence direct compact-block announcement decisions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-113-01-01 | Tampering | `CompactRelayPeerState::apply_send_compact` | mitigate | Treat only `BIP152_COMPACT_BLOCKS_VERSION` as supported; unsupported versions set `maybe_unsupported_version` and stable unsupported state without marking the peer version-2 capable. |
| T-113-01-02 | Denial of Service | `PeerManager::handle_message` sendcmpct branch | mitigate | Keep the transition O(1), allocation-free except normal enum updates, and return no actions so repeated unsupported messages cannot trigger disconnect churn or outbound message bursts. |
| T-113-01-03 | Elevation of Privilege | `PeerState` compact relay fields | mitigate | Tests must prove transaction relay and `remote_wtxidrelay` do not activate compact relay capability. |
| T-113-01-04 | Information Disclosure | Negotiation outcome reasons | mitigate | Use fixed enum values only; do not store raw peer endpoints, permission strings, block hashes, transaction IDs, or dynamic labels. |
| T-113-01-05 | Spoofing | Per-peer compact state lookup | mitigate | Update only the `peer_id` matched by `PeerManager::peer_mut`; unknown peers still return `NetworkError::UnknownPeer`. |
</threat_model>
