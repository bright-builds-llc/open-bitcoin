## Security And Correctness Notes

- New status fields are additive and must remain serde-compatible for existing
  status snapshots.

  downloaded-only block body. The fields must be populated from the connected
  active-chain tip only.
- Cumulative work is exposed as a decimal string to avoid JSON number precision
  ambiguity for downstream tooling.
</threat_model>
