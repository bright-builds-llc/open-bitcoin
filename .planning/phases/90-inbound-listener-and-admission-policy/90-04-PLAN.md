<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Network socket to runtime adapter | Untrusted TCP peers can connect and send wire messages. |
| Runtime listener to daemon lifecycle | Listener tasks must stop cleanly with daemon shutdown and not leak accept loops. |
| Runtime logs to operator evidence | Logs can reveal endpoints or overstate serving capabilities. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-90-04-01 | Information Disclosure | listener binding | mitigate | Default disabled, loopback-first tests, public/wildcard endpoints require explicit `allow_public`. |
| T-90-04-02 | Denial of Service | accept loop | mitigate | Start bounded listener tasks only after typed activation and tie shutdown to daemon signal. |
| T-90-04-03 | Tampering | inbound wire messages | mitigate | Use existing message codec and PeerManager state transitions; no second parser. |
| T-90-04-04 | Repudiation | startup/log evidence | mitigate | Emit stable labels for listener state, preflight reason, endpoint, and admission rejection. |
</threat_model>
