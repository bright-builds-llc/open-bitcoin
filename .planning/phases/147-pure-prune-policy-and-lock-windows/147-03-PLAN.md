```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ManualPruneInput {
    pub tip: u32,
    pub prune_after_height: u32, // injected
    pub mode: PruneMode,
    pub target_height: u32,
    /// Optional presence filter: if Some, only heights present in the map are candidates.
    /// If None, every height in 0..=effective_end that is not lock-forbidden is a candidate.
    pub maybe_present_heights: Option<std::collections::BTreeSet<u32>>,
    pub locks: Vec<PruneLockInfo>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ManualPruneRefusal {
    Disabled,
    ChainTooShort { tip: u32, prune_after_height: u32 },
    TargetInsideKeepWindow { tip: u32, target: u32, last_prunable: u32 },
    TargetAboveTip { tip: u32, target: u32 },
}

pub fn plan_manual_prune(input: &ManualPruneInput) -> Result<PrunePlan, ManualPruneRefusal>;
```

Manual algorithm (D-07, D-08; research §3 — **do not clamp**):

1. If `mode == Disabled` → `Err(Disabled)`. Note: `ManualOnly` **and** `Automatic {..}` both allow manual prune requests (Knots `IsPruneMode` is prune_target &gt; 0). Only Disabled refuses.
2. If `tip &lt; prune_after_height` → `Err(ChainTooShort { tip, prune_after_height })`.
   - Note asymmetry vs automatic: automatic empty when `tip &lt;= prune_after`; manual errors when `tip &lt; prune_after`. When `tip == prune_after_height`, manual is allowed (Knots RPC).
3. If `target_height &gt; tip` → `Err(TargetAboveTip { tip, target: target_height })`.
4. If `height_inside_keep_window(tip, target_height)` i.e. `target_height &gt; tip.saturating_sub(288)` → `Err(TargetInsideKeepWindow { tip, target: target_height, last_prunable: last_prunable_height(tip) })`.
   - Explicit fixtures: tip=1000, target=713 → refuse; tip=1000, target=712 → allowed.
   - **Do not** implement Knots RPC clamp to `tip-288` (locked D-07 / PRUN-03).
5. `effective_end = min(target_height, last_prunable_height(tip))`.
6. Build ascending heights `h` in `0..=effective_end` (D-14 prune_start=0):
   - If `maybe_present_heights` is `Some(set)` and `h` not in set → skip.
   - If `height_forbidden_by_any_lock(h, &locks)` → skip (omit; do not fail) (D-10).
   - Else push `h`.
7. Return `Ok(PrunePlan { heights })`. Do **not** consult byte sizes / current_usage (D-08 — no automatic budget walk).
