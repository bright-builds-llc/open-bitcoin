Add in `prune/plan.rs` this plan:

```rust
#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct PrunePlan {
    pub heights: Vec<u32>, // ascending, unique, eligible candidates only
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AutomaticPruneInput {
    pub tip: u32,
    pub prune_after_height: u32, // injected chain-params fact — never hardcoded mainnet
    pub mode: PruneMode,
    /// Ascending height → payload byte size. Missing heights are treated as size 0 / absent.
    pub height_sizes: std::collections::BTreeMap<u32, u64>,
    /// Total current usage in bytes (sum of payload sizes the adapter attributes to pruneable storage).
    pub current_usage_bytes: u64,
    pub locks: Vec<PruneLockInfo>,
}

/// Always returns a plan (possibly empty). Never Err for prune-after / under-target / Disabled.
pub fn plan_automatic_prune(input: &AutomaticPruneInput) -> PrunePlan;
```

Algorithm (locked research §6; omit Knots 17 MiB chunk buffer — Fjall layout difference for Phase 151):

1. If `mode` is not `Automatic { target_mib }` → return empty `PrunePlan` (Disabled/ManualOnly do not auto-walk).
2. If `!automatic_prune_allowed(tip, prune_after_height)` i.e. `tip &lt;= prune_after_height` → empty plan (D-05; not an error).
3. `target_bytes = target_mib * 1024 * 1024`.
4. If `current_usage_bytes &lt;= target_bytes` → empty plan.
5. `last = last_prunable_height(tip)` (`tip.saturating_sub(288)`). Eligible heights are those in `height_sizes` with `h &lt;= last` (single chainstate prune_start = 0; D-14 — no snapshot branch).
6. Walk eligible heights **ascending** (oldest first). For each height:
   - If `height_forbidden_by_any_lock(h, &locks)` → **skip** (continue); do not fail the plan (D-10).
   - Else include `h` in the plan and subtract `height_sizes[h]` from a running `remaining_usage` (start from `current_usage_bytes`).
   - Stop when `remaining_usage &lt;= target_bytes` **after** subtracting a selected candidate (research Open Question 1 locked here).
7. Return `PrunePlan { heights }` ascending. Empty is success.
