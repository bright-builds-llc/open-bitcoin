## Trust Boundaries

| Operator CLI args -> soak executor | Untrusted command-line values become durable run bounds and file paths. |
| Soak executor -> status collector | The local CLI reads status evidence from existing runtime/status surfaces. |
| Soak executor -> datadir ledger | The command writes run events into the selected datadir. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-75-02-01 | Tampering | `soak resume` | mitigate | Validate selected datadir identity and run id against the run index before appending `Resume`. |
| T-75-02-02 | Spoofing | `soak start` final outcome | mitigate | Classify outcomes only from `SyncStopReasonStatus`, `SyncRecoveryCategory`, `NoProgressDiagnosis`, `FullSyncEvidence`, and explicit process facts. |
| T-75-02-03 | Denial of Service | `soak start` | mitigate | Require positive elapsed/checkpoint/disk bounds; do not run public-network scripts or service-manager commands from default tests. |
| T-75-02-04 | Information Disclosure | command output | mitigate | Output only ledger/report paths, run id, sequence, and final outcome; do not print cookies, RPC passwords, raw logs, or wallet material. |
| T-75-02-05 | Elevation of Privilege | daemon authority boundary | accept | This plan does not add daemon mutation or a new privilege boundary; `open-bitcoind` and existing runtime config remain authoritative for sync behavior. |
</threat_model>
