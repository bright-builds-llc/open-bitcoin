```rust
// packages/open-bitcoin-node/src/chainstate/replay.rs
pub fn replay_interrupted_flush(
    store: &FjallNodeStore,
    view: FjallCoinsView,
) -> Result<FjallCoinsView, StorageError>;
```

Algorithm (Knots ReplayBlocks, apply-only — D-07):
1. `heads = view.head_blocks()`. `decide_recovery(heads.len())`.
2. `ConsistentEmptyHeads` or `OneHead` → return `view` unchanged (D-09).
3. `InconsistentOtherCount` → `StorageError::Corruption { namespace: Coins, action: Repair }`.
4. `InterruptedTwoHeads`: `new = heads[0]`, `old = heads[1]`.
5. Build `CoinsCache::from_parent(view)` (empty overlay; do not probe B).
6. If `old != BlockHash::from_byte_array([0;32])`: walk `old` back to the fork with `new` using `store.load_header_store()?.entry(hash).header.previous_block_hash`. For each disconnected hash, `load_block` + `load_undo` required. Restore undo coins with `CoinsCache::add_coin(..., possible_overwrite = true)` and spend created outputs. Missing any body/undo → `StorageError::InterruptedWrite { namespace: Coins, action: Reindex }` and **do not** `flush` or erase H (D-08).
7. Walk `fork` exclusive → `new` inclusive. For each block: `load_block` required. For each non-coinbase tx: `spend_coin` each input (treat already-spent as idempotent success if `MissingCoin`), then `add_coin` each output with `possible_overwrite = true` using `created_height` / MTP from the header entry. Missing body → same `InterruptedWrite`, H remains.
8. `cache` best block = `new`. Flush via `batch_write_with_persist_mode(..., PersistMode::Sync)` (141 D-08 marker finish). That existing two-phase write clears H and writes B.
9. Return `FjallCoinsView::from_store(store)`.

`FjallCoinsView::batch_write` today hardcodes `persist_mode_for_final_best_block() -> PersistMode::Flush`. Add:
```rust
pub fn batch_write_with_persist_mode(
    &mut self,
    writes: CoinsBatch,
    maybe_best_block: Option<BlockHash>,
    final_mode: PersistMode,
) -> Result<(), ChainstateError>;
```
Keep the no-arg `batch_write` calling Flush. Replay and later Always use Sync.

Do not call `Chainstate::connect_block`. Do not put this in `flush.rs` (existing source test forbids `ReplayBlocks` / `BlockHash` there). Do not auto-reindex (FUT-23).
