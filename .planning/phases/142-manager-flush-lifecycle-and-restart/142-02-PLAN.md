Occupancy (D-05) on `CoinsCache<V>`:
```rust
pub const ESTIMATED_COIN_ENTRY_OVERHEAD_BYTES: u64 = 48;
pub fn cache_entry_count(&self) -> u64; // overlay.entries.len() as u64
pub fn estimated_cache_bytes(&self) -> u64;
```
Per-entry bytes = `48 +` (if unspent: `8` value sats + `script_pubkey` byte len + `4` height + `8` MTP + `1` coinbase). Spent entries count overhead only. Do not call Fjall `len()` or LevelDB `SizeEstimate`. Do not pin 450/4/8 MiB in this crate (D-04).

Do not edit node persist, replay, or `ManagedChainstate`.
