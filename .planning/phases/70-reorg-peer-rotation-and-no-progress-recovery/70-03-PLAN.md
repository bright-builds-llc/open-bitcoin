## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public peer response -> in-flight bookkeeping | Untrusted peers can send `notfound`, malformed, invalid, duplicate, disconnected, or non-extending block responses. |
| peer endpoint -> retry/backoff state | Endpoint-keyed failures affect retry timing and peer rotation. |
| sync runtime -> operator peer outcomes | Operators rely on typed peer outcomes to distinguish retryable peer problems from storage blockers. |

| T-70-03-04 | Elevation of Privilege | peer governance scope | accept | Phase 70 is outbound sync only; no inbound reputation, banning, relay, or address-manager authority is added. |
</threat_model>
