<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public peer headers/blocks -> header store and chainstate | Untrusted branch and block data can attempt to influence active-chain selection. |
| durable store -> reorg execution | Local block bodies, undo evidence, and chainstate snapshots are trusted only after typed storage loading succeeds. |
| sync runtime -> operator status | Status must not claim a new active tip until persistence completes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-70-02-01 | Tampering | `reconcile_best_chain` | mitigate | Require cumulative-work, height, hash ordering and replacement bodies before disconnecting the current active chain. |
| T-70-02-02 | Tampering / Denial of Service | active-chain disconnect evidence loading | mitigate | Map missing active-chain block bodies, missing undo data, and malformed stored chainstate to storage repair blockers, not peer retry. |
| T-70-02-03 | Repudiation | durable latest reorg projection | mitigate | Persist bounded latest evidence with ancestor, counts, final tip, and persisted verdict in `RuntimeMetadata.maybe_sync_state`. |
| T-70-02-04 | Information Disclosure | operator reorg status | mitigate | Expose bounded counts and hashes only; never include raw undo payloads or raw stored block bodies. |
</threat_model>
