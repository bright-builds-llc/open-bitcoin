| Boundary | Description |
|----------|-------------|
| public peer -> managed network | A peer can send malformed, invalid, duplicate, disconnected, or non-extending block bodies. |
| managed network -> sync shell | Connect disposition crosses from validation/connect logic into telemetry and durable save decisions. |
| sync shell -> active chainstate | Only validated extending blocks may advance active chainstate. |
