<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| peer inventory -> pure serving classifier | Untrusted inventory type/hash is parsed into TxRelayId or rejected as fixed-label evidence. |
| mempool outcome -> pure fanout policy | Runtime admission facts are converted into bounded fanout actions without side effects. |
| policy evidence -> future status/docs | Labels may become operator-visible later and must remain fixed and low-cardinality. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-104-01-01 | Tampering | `classify_tx_serve_request` | mitigate | Use `TxRelayId::from_inventory_vector_for_peer` for every transaction inventory vector and return `identity_mismatch` or `not_transaction_inventory` before any served decision. |
| T-104-01-02 | Information Disclosure | `TxServeOutcomeLabel` | mitigate | Emit only fixed labels and no transaction hex, txid, wtxid, peer id, endpoint, permission string, class name, or credential values. |
| T-104-01-03 | Denial of Service | `TxFanoutQueue` | mitigate | Enforce `PHASE104_MAX_TX_FANOUT_QUEUE_PER_PEER`, `PHASE104_MAX_TX_FANOUT_DRAIN_PER_PEER`, and caller-provided fake-clock rate limits in pure tests. |
| T-104-01-04 | Elevation of Privilege | fanout eligibility | mitigate | Require `RelayEligibilityDecision.eligible == true`; protected admission alone cannot enqueue fanout. |
| T-104-01-05 | Repudiation | rebroadcast boundary | mitigate | Represent rebroadcast as `rebroadcast_deferred` and add tests proving no timer or public propagation claim is introduced. |
</threat_model>
