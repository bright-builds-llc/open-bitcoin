<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator docs to local service actions | Service docs can influence launchd/systemd install, start, stop, restart, disable, and uninstall decisions on an operator machine. |
| Runtime evidence to support interpretation | Service status, logs, metrics, resource evidence, and support bundles can be overread as production service proof if fields are not named. |
| Support guidance to shared artifacts | Redacted local evidence can accidentally include secrets, raw logs, wallet data, or support-upload expectations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-86-01 | Spoofing | `docs/parity/service-operation-expectations.md` service support wording | mitigate | Require exact Phase 82 support terms and classify production service ownership, uptime guarantees, packaged services, Windows service integration, automatic updates, and broad production full-node readiness as `deferred`. |
| T-86-02 | Tampering | Service-manager mutation boundary | mitigate | State that preview is side-effect-free, install/uninstall are previews unless `--apply` is supplied, and real lifecycle actions are opt-in local UAT outside default verification. |
| T-86-03 | Repudiation | Field-based evidence interpretation | mitigate | Require lifecycle labels, restart/resume fields, status JSON, sync status JSON, service log path, manager command strings, generated service file path, resource/recovery fields, and unavailable reasons. |
| T-86-04 | Information Disclosure | Support evidence guidance | mitigate | Forbid wallet private material, raw wallet files, RPC cookies, `rpcpassword`, `rpcauth`, raw datadirs, unredacted logs, raw unbounded logs, and automatic support-bundle upload. |
| T-86-05 | Denial of Service | Default verification expectations | mitigate | Keep public-network, real-service-manager, and multi-day evidence opt-in UAT only; require the deterministic verifier boundary sentence in the canonical doc. |
</threat_model>
