## Trust Boundaries

| Boundary | Description |
| --- | --- |
| peer bytes -> `decode_compact_block_payload` | Untrusted compact-block payload bytes become typed header, nonce, short IDs, and prefilled transactions. |
| compact payload -> later reconstruction phases | Structurally valid payloads may be consumed by future partial reconstruction state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-112-02-01 | Tampering | `ShortId` | mitigate | Encode short IDs only through `ShortId([u8; 6])`; tests assert exactly six wire bytes and prevent eight-byte emission. |
| T-112-02-02 | Denial of Service | short ID and prefilled counts | mitigate | Reuse CompactSize `MAX_SIZE`, reject total implied transaction count above `u16::MAX`, and validate before future partial state. |
| T-112-02-03 | Tampering | prefilled differential indexes | mitigate | Use checked differential expansion and reject overflow, out-of-range indexes, and positions beyond implied count. |
| T-112-02-04 | Tampering | witness transaction serialization | mitigate | Use `TransactionEncoding::WithWitness` for every prefilled transaction and rely on the existing transaction parser for superfluous witness rejection. |
| T-112-02-05 | Elevation of Privilege | `cmpctblock` message mapping | mitigate | Keep `cmpctblock` separate from `GetData`, `Block`, node-shell serving, mempool lookup, and peer policy. |
</threat_model>
