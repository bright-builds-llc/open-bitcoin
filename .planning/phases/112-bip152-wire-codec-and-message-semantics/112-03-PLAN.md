<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| peer bytes -> `decode_get_block_transactions_payload` | Untrusted missing-transaction request bytes become block hash plus bounded transaction indexes. |
| peer bytes -> `decode_block_transactions_payload` | Untrusted transaction response bytes become witness-preserving transaction payloads. |
| malformed BIP152 bytes -> network message errors | Malformed payloads cross into the network layer and must remain typed errors, not peer policy side effects. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-112-03-01 | Tampering | `getblocktxn` indexes | mitigate | Decode differential indexes with checked arithmetic and reject absolute positions above `u16::MAX`. |
| T-112-03-02 | Tampering | `blocktxn` transaction serialization | mitigate | Always encode and decode with witness support; no no-witness `blocktxn` branch is introduced. |
| T-112-03-03 | Denial of Service | malformed vector counts | mitigate | Reuse CompactSize canonical and `MAX_SIZE` checks, plus malformed matrix tests for bad counts and trailing bytes. |
| T-112-03-04 | Repudiation | malformed error ambiguity | mitigate | Assert stable `CodecError`/`NetworkError` display strings for representative malformed `cmpctblock`, `getblocktxn`, and `blocktxn` cases. |
| T-112-03-05 | Elevation of Privilege | `blocktxn` peer consequences | mitigate | Keep in-flight matching, peer identity, fallback, misbehavior, disconnect, and validation handoff out of the codec and message layer. |
</threat_model>
