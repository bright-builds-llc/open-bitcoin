    pub struct MaintenanceIdentitySelection&lt;T&gt; {
        pub inspected: Vec&lt;T&gt;,

    Walk rule (must implement exactly):
    1. If `members` is empty, return empty vectors and the input `maybe_after`.
    2. Start at the first member strictly greater than `maybe_after`, or the first member if `maybe_after` is `None` or greater than every member.
