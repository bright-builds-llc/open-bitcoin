## Trust boundaries

| Boundary | Risk | Required control |
| --- | --- | --- |
| TCP bytes to frame | Partial untrusted frames can masquerade as idle | Only zero-progress header timeout is Idle; partial header/payload failures are errors |
| Caller clock to timeout state | Stale/duplicated time suppresses or duplicates fallback | One required clock call and one existing expiration call per Idle |
| Targeted action to socket | Another peer's fallback can leak | Preserve PeerId and fail with a fixed error before mismatch write |
