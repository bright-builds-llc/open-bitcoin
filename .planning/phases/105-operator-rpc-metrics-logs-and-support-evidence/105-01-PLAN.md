# Phase 105 Plan 01: Shared Relay Status And RPC Projection

<objective>
Create the single typed relay and mempool evidence contract used by later operator, metrics, log, and support surfaces, then expose it through Open Bitcoin-specific RPC without changing baseline-compatible RPC response shapes.
</objective>

<context>
Phase 105 must make operator-facing relay truthfulness auditable while avoiding public relay, compact block, or production readiness claims. Existing relay evidence is scattered across node status snapshots, local relay fanout records, local relay serving records, and RPC network context. This plan creates the shared sanitized projection first so downstream surfaces can render one source of truth instead of reconstructing relay state independently.
</context>
