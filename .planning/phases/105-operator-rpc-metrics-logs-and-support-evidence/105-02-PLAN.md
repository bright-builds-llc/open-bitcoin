# Phase 105 Plan 02: CLI, Dashboard, Metrics, And Logs

<objective>
Render the Phase 105 relay and mempool evidence contract through operator CLI, dashboard, metrics, and structured logs without introducing sensitive values or dynamic metric labels.

Plan 105-01 establishes the sanitized source of truth. This plan makes operator surfaces consume that source instead of inventing their own relay state. The CLI and dashboard must be useful for UAT, while metrics and logs must remain low-cardinality and safe for support bundles.
