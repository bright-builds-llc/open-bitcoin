## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Fjall `get`/`contains_key` → `CoinsView` | Backend `Err` or corrupt bytes cross into domain lookups. |
| Mid-flush `H` marker → reopen | A two-element `H` means mixed old/new coins; treating it as consistent invents a tip. |
| Encoded-byte accumulator → Fjall commit | Using item count as 64 MiB leaves huge batches or splits wrongly. |
