## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Fjall bytes → `decode_coin_value` | Untrusted on-disk bytes become `Coin`; trailing or short data must not become a spendable UTXO. |
| Parent `CoinsView` → `CoinsCache` | Disk/parent errors cross into cache lookups; mapping them to miss/spent elevates a failed read into an empty UTXO set. |
| Pure-core crate → I/O | Fjall or filesystem in `open-bitcoin-chainstate` would break the functional-core boundary. |
