7. Write schema version `2` with `PersistMode::Sync`.

1. Call `FjallCoinsView::from_store(self).head_blocks()` **before any `C`-prefix scan**. 2. If leftover snapshot present AND coins empty → `Corruption` / `RestoreFromBackup` (should already have failed in `ensure_schema`; keep the check).
3. If coins exist (`B` or any `C` key) **and `H` is empty/absent**: scan `C` prefix into `utxos`; load all `undo:` values; load `chain_meta` for `active_chain` / counts; if `chain_meta` is missing, read leftover snapshot *metadata only* (`active_chain`, `maybe_confirmed_txid_counts`) and never leftover `utxos`.
4. If coins empty and no leftover: return `Ok(None)` (fresh datadir).
