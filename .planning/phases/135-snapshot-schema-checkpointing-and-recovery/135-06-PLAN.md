## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Stored snapshot to startup runtime | Persisted source must be validated before concurrent producers see state. |
| Runtime workers to shutdown checkpoint | Producer quiescence determines whether final capture is current. |
| Final checkpoint to clean marker | A clean claim is valid only after exact-current Sync durability. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-135-06-01 | Tampering | Unsafe legacy/corrupt startup | mitigate | Bounded explicit decoder, staged validation, original-byte retention, no empty fallback. |
| T-135-06-02 | Denial of Service | Startup graph/snapshot | mitigate | Enforce decode and graph limits before install; no partial live state. |
| T-135-06-03 | Tampering | Shutdown race | mitigate | Join every mutation producer before final capture and clean-marker write. |
| T-135-06-04 | Repudiation | False clean shutdown | mitigate | Require Sync success and last-durable == current before `mark_clean_shutdown`. |
| T-135-06-05 | Denial of Service | Periodic worker | mitigate | One private worker, five-minute interval, single-flight/coalescing, and clean skip. |
| T-135-06-06 | Information Disclosure | Startup/shutdown diagnostics | mitigate | Log fixed failure classes and generations only; never raw bytes or identities. |
</threat-model>
