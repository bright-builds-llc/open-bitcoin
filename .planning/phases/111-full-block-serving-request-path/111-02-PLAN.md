<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| peer-manager -> node-shell inventory adapter | Accepted untrusted inventory requests can trigger storage/cache reads and outbound messages. |
| Phase 110 policy -> local block cache | Pure eligibility/status/resource decisions decide whether effectful cache reads are allowed. |
| local chain/cache state -> peer response | Chain position and local bytes determine whether a peer receives a block or `notfound`. |
| inbound permission evidence -> serving eligibility | Permissioned/protected peers can influence eligibility but must not bypass caps or archive boundaries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-111-02-01 | Denial of Service | `ManagedPeerNetwork::serve_inventory` | mitigate | Adapter calls `evaluate_block_serving_resource_gate` with existing request counts before returning `maybe_block`; tests cover permissioned cap pressure and over-cap outcomes. |
| T-111-02-02 | Elevation of Privilege | permissioned/protected inbound peers | mitigate | Eligibility uses `active_effects()` and `DownloadServingPolicyInput` only with explicit activation and inbound serving enabled; tests prove permissions do not bypass caps. |
| T-111-02-03 | Tampering | cached side-chain/unvalidated blocks | mitigate | Status facts classify cached non-active blocks as side-chain/unknown and deny storage return; tests prove cache presence alone cannot serve. |
| T-111-02-04 | Information Disclosure | unavailable block probes | mitigate | Missing local block data returns `NotFound` and fixed labels such as `block_status_unavailable`; tests reject raw peer, permission, credential, and payload leakage. |
| T-111-02-05 | Spoofing | archive-node or public-serving implication | mitigate | Activation is explicit and default-off, serving is cache/status gated, docs/checker plan follows to reject archive/public/default claims. |
| T-111-02-06 | Tampering | compact block request scope | mitigate | `InventoryType::CompactBlock` maps to `BlockServingSuppressed` and `NotFound`; no `cmpctblock`, `getblocktxn`, `blocktxn`, or full-block fallback is emitted in Phase 111. |
</threat_model>
