## Critical Gaps

### GAP-01: Release-Readiness Checklist Missing Phase 88 Rows

Affected requirements: REL-01, REL-02, REL-03, REL-04

The `## v1.8 Release Readiness Checklist` table in `docs/parity/release-readiness.md` lists PROD, SUP, UPG, RUN, SVC, REL-01, REL-05, and REL-06 rows. It does not include REL-02, REL-03, or REL-04 rows after Phase 88 added deterministic claim guardrails. The page references Phase 88 in prose, but the checklist promises to map every current v1.8 requirement to evidence, verification, UAT/manual posture, residual risk, and no-claim or next-gate status.

Evidence:

- `docs/parity/release-readiness.md:286` starts the checklist table.
- `docs/parity/release-readiness.md:315` includes REL-01.
- `docs/parity/release-readiness.md:316` includes REL-05.
- `docs/parity/release-readiness.md:317` includes REL-06.
- `docs/parity/release-readiness.md:343` says Phase 88 owns REL-02, REL-03, and REL-04, but that is outside the checklist table.

Required closure:

- Add REL-02, REL-03, and REL-04 rows to the v1.8 release-readiness checklist.
- Keep the rows linked to the Phase 88 checker, fixture tests, parity roots, `scripts/verify.sh`, and the no-production-readiness boundary.
- Update the Phase 87/Phase 88 checker expectations if needed so this gap cannot recur.

### GAP-02: Phase 88 Guardrail Corpus Omits Canonical v1.8 Policy Docs

Affected requirements: REL-02, REL-03

The Phase 88 checker scans a curated corpus, but omits three canonical v1.8 release-review evidence docs:

- `docs/parity/upgrade-and-rollback-policy.md`
- `docs/parity/operator-runbooks.md`
- `docs/parity/service-operation-expectations.md`

Those documents are first-class v1.8 policy roots linked from the release-readiness page and entrypoint docs. A deferred-surface production-ready claim in any of them would not currently be caught by the Phase 88 broad guardrail.

Evidence:

- `scripts/check-phase88-deterministic-claim-guardrails.ts:16` defines `TARGET_FILES`.
- Current `TARGET_FILES` includes `README.md`, `docs/operator/runtime-guide.md`, `production-claim-boundary.md`, `support-matrix.md`, `release-readiness.md`, `deviations-and-unknowns.md`, parity roots, the operator-runtime catalog, and `scripts/verify.sh`.
- Current `TARGET_FILES` does not include the upgrade policy, operator runbooks, or service expectation docs.

Required closure:

- Add the missing canonical policy docs to the Phase 88 scan corpus unless a narrower explicit rationale is documented.
- Add fixture coverage that proves deferred-surface promotion in those docs fails the checker.
- Rerun focused Phase 88 checks and full repo-native verification after the fix.
